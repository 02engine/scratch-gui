# FormattedMessage 多语言注册指南

## 核心原理

这个项目的 i18n 系统分 3 层：

```
组件 JSX 中的 <FormattedMessage id="xxx" defaultMessage="英文" />
        ↓ babel-plugin-react-intl 提取
translations/messages/src/.../*.json  (消息定义，英文源)
        ↓
generated-translations.json           (各语言翻译，手动/Transifex 维护)
        ↓ 运行时 Object.assign 合并
Redux state.locales.messages          (当前语言的所有消息)
        ↓ ConnectedIntlProvider
<FormattedMessage> 渲染翻译文本
```

## 你要做的 2 件事

### 第 1 步：在组件中使用 FormattedMessage（你已经做了）

```jsx
<FormattedMessage
    defaultMessage="UI Layout Mode"
    description="UI layout mode setting label"
    id="tw.settingsModal.uiLayoutMode"
/>
```

这一步定义了消息 ID 和英文默认文本。`babel-plugin-react-intl` 会自动提取到：
`translations/messages/src/components/tw-settings-modal/settings-modal.json`

### 第 2 步：在 generated-translations.json 中添加翻译

文件位置：`src/lib/tw-translations/generated-translations.json`

这是个大 JSON，按语言分块。找到你要的语言 key（如 `"zh-cn"`），在里面加一行：

```json
"zh-cn": {
    ...已有的翻译...
    "tw.settingsModal.uiLayoutMode": "UI 布局模式",
    "tw.settingsModal.legacyUI": "经典 UI",
    "tw.settingsModal.new02eUI": "02E 新版"
}
```

**就这么多。** ID 匹配上就能自动生效，不需要 import 任何东西、不需要调用任何注册方法。

## 本次重构需要添加的翻译条目

| 消息 ID | 英文 defaultMessage | 中文翻译建议 |
|---------|---------------------|-------------|
| `tw.settingsModal.uiLayoutMode` | `UI Layout Mode` | `UI 布局模式` |

下拉选项的显示名（`Legacy UI` / `02E New`）目前是硬编码在 `UI_LAYOUT_MODE_LABELS` 中的纯字符串，不走 react-intl。如果也要翻译，需要额外改动（见下方"进阶"）。

## 翻译文件中已有的 settingsModal 条目参考

`generated-translations.json` 的 `zh-cn` 段中已有这些翻译：
- `tw.settingsModal.highQualityPen` → "高质量画笔"
- `tw.settingsModal.fps` → "60帧每秒（自定义帧率）"

## 进阶：如果下拉选项名也要翻译

需要改 `ui-layout-modes.js`，把 label 从硬编码字符串改成 react-intl message descriptor：

```js
// ui-layout-modes.js
export const UI_LAYOUT_MODE_MESSAGES = {
    [UI_LAYOUT_MODES.LEGACY]: {
        id: 'tw.settingsModal.legacyUI',
        defaultMessage: 'Legacy UI'
    },
    [UI_LAYOUT_MODES.NEW_02E]: {
        id: 'tw.settingsModal.new02eUI',
        defaultMessage: '02E New'
    }
};
```

然后在 settings-modal.jsx 的 CustomUI 组件中用 `intl.formatMessage()` 来获取翻译文本：

```jsx
const CustomUI = injectIntl(props => {
    const selectedIndex = ...;
    const items = Object.values(UI_LAYOUT_MODES).map(mode => ({
        value: mode,
        title: props.intl.formatMessage(UI_LAYOUT_MODE_MESSAGES[mode]),
        onSelect: () => props.onChange(mode)
    }));
    return (
        <Setting ...>
            <Select items={items} selectedIndex={selectedIndex} />
        </Setting>
    );
});
```

对应的 `generated-translations.json` 新增：
```json
"zh-cn": {
    "tw.settingsModal.uiLayoutMode": "UI 布局模式",
    "tw.settingsModal.legacyUI": "经典 UI",
    "tw.settingsModal.new02eUI": "02E 新版"
}
```

## 关键文件

| 文件 | 作用 |
|------|------|
| `src/lib/tw-translations/generated-translations.json` | **翻译入口**，在这里加翻译 |
| `translations/messages/src/components/tw-settings-modal/settings-modal.json` | 消息定义（babel 自动提取） |
| `src/lib/tw-translations/index.js` | 运行时合并翻译到 editor messages |
| `src/reducers/locales.js` | Redux 中管理 locale 和 messages |
| `src/lib/connected-intl-provider.jsx` | 连接 Redux 和 react-intl IntlProvider |
